# Failed Banks Project

A Power BI Desktop report on failed US banks.

- **File:** [Failed_Banks_Project.pbix](Failed_Banks_Project.pbix) (open with Power BI Desktop)
- **Data:** public failed-bank list (`failed-banks` table) plus a `Calender` date table

## Report pages

### Overview

- **Bar chart:** number of failed banks by state
- **Column chart:** number of failed banks by month
- **Matrix:** banks by state, drillable to city

### Tooltip page

- **Azure map:** failed banks by city and state, shown as a tooltip on hover
